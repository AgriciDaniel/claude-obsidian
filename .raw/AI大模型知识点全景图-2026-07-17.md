### 4. Training Methodologies
- **Pre-training**: Next-token prediction, causal LM, masked LM
- **Supervised Fine-Tuning (SFT)**: Instruction tuning, multi-turn dialogue tuning
- **RLHF** (Reinforcement Learning from Human Feedback): Reward model training, PPO optimization
- **DPO** (Direct Preference Optimization): Simplified alternative to RLHF
- **GRPO** (Group Relative Policy Optimization): DeepSeek's approach
- **Constitutional AI**: Anthropic's approach to safety training
- **Alignment techniques**: Value alignment, harmlessness training
- **Continual pre-training**: Domain-adaptive pre-training
- **Multi-task learning**

### 5. Key Techniques & Methods
- **Prompt Engineering**: Zero-shot, few-shot, chain-of-thought, tree-of-thought
- **RAG** (Retrieval-Augmented Generation): Chunking, embedding, retrieval, generation pipeline
- **In-Context Learning (ICL)**: How models learn from examples in context
- **Function Calling / Tool Use**: Model as controller
- **Structured Output**: JSON mode, grammar-constrained generation
- **Quantization**: GPTQ, AWQ, GGUF, bitsandbytes (int8, int4, NF4)
- **KV-cache optimization**: MHA → GQA → MQA evolution
- **Speculative Decoding**: Draft model + target model for faster inference
- **Knowledge Distillation**: Teacher → student compression
- **LoRA / QLoRA**: Parameter-efficient fine-tuning
- **Model Merging**: Model soup, TIES, DARE

### 6. Reasoning & Advanced Capabilities
- **Chain-of-Thought (CoT)**: Step-by-step reasoning
- **Tree-of-Thought (ToT)**: Branching exploration
- **Graph-of-Thought (GoT)**: Graph-structured reasoning
- **Self-Consistency**: Multiple reasoning paths → majority vote
- **ReAct**: Reasoning + Acting loop
- **Reflexion**: Self-reflection and error correction
- **Mixture of Agents (MoA)**: Multi-agent collaboration for better reasoning
- **Test-Time Compute Scaling**: Compute at inference time (o1, o3, DeepSeek-R1)

### 8. AI Safety & Alignment
- **Red teaming**: Human red team, automated red team (stronger model tests weaker)
- **Jailbreak attacks**: Prompt injection, role-play, hypothetical scenarios
- **Defense mechanisms**: Input/output filtering, RLHF guardrails, system prompts
- **Content moderation**: NSFW filtering, hate speech, bias mitigation
- **Watermarking**: Model output detection, statistical watermarking (Aaronson, Kirchenbauer)
- **Constitutional AI**: Harmlessness via principles, not RLHF alone
- **Data privacy**: Training data contamination, memorization, PII leakage
- **Copyright & IP**: Training data lawsuits, fair use doctrine, licensing models for data
