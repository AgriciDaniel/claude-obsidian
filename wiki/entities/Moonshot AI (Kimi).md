# Moonshot AI (Kimi)

月之暗面（Moonshot AI）由前清华大学教授杨植麟创立，其 Kimi 系列以超长上下文处理和强大的推理能力著称。

## 模型时间线

| 模型 | 发布时间 | 特点 |
|------|----------|------|
| Kimi | 2023-10 | 超长上下文（首批 200K） |
| Kimi k1.5 | 2025-01 | 推理增强、在多项基准接近 o1 |
| Kimi k2 | 2025-05 | 更进一步的推理能力 |

## Kimi k1.5 的突破

Kimi k1.5 是 2025 年初最受关注的推理模型之一，在多项基准上接近 OpenAI o1 的水平。

### 关键技术
- **长上下文扩展**: 以超长上下文（200K+）为基础训练
- **RL 训练推理**: 类似 DeepSeek-R1，用强化学习训练推理链
- **多模态推理**: Kimi k1.5 支持文本和图像混合输入推理

### 基准表现
- 代码（HumanEval、Codeforces）：接近 GPT-4
- 数学（MATH、AIME）：接近 o1
- 长上下文：行业领先

## 产品特色

| 产品 | 类型 | 说明 |
|------|------|------|
| Kimi Chat | C 端聊天助手 | 超长上下文对话 |
| Kimi API | API 服务 | 开放平台 |
| Kimi浏览器插件 | 浏览器 | 网页阅读、PDF 分析 |

### 用户体验亮点
- **文档分析**: 可一次性处理数百页 PDF、超长网页
- **多文件对话**: 同时上传和分析多个文件
- **联网搜索**: 实时信息检索
- **自然对话**: 中文对话流畅自然，C 端口碑极佳

## 市场定位
- **C 端产品力强**: Kimi Chat 是国内用户量最大的独立 AI 对话产品之一
- **差异化": 以超长上下文为招牌功能（"一次看完整本书"）
- **推理新锐**: k1.5 验证了其在基础模型能力上的突破
- **投资背景**: 获得阿里等头部机构投资
