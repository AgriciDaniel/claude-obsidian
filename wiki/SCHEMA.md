# Wiki Schema

## Domain

Personal/project engineering knowledge base for Manaz's active repos, agent handoffs, durable project memory, and high-signal operating notes.

## Conventions

- Project notes live under `wiki/projects/{project}/`.
- Canonical project pages: `INDEX.md`, `ARCHITECTURE.md`, `SETUP.md`, `DEPLOYMENT.md`, `DATA-MODEL.md`, `API.md`, `DECISIONS.md`, `TODO.md`.
- Cross-project notes live under `wiki/engineering/`.
- Use Obsidian wikilinks for related notes.
- Keep notes concise. No source-file dumps.
- Never include secrets, tokens, `.env` values, private keys, or credentials.
- For Zawiya, do not digitize private spiritual content, awrad, wirds, teacher instructions, private screenshots, or unapproved recordings.
- If uncertain, write `Unknown` or `Needs verification`.
