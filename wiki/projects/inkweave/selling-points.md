# InkWeave — Selling Points

## Core USPs

1. **Snippets only — no blank page terror.** User doesn't need a plan. Drop raw fragments, InkWeave builds structure.
2. **Full book, not a prompt tool.** Output is a complete manuscript, not a paragraph. 50,000–100,000 words.
3. **Session remote control.** User can redirect the AI mid-generation. Not a black box.
4. **UK-native.** Pricing in GBP, UK publishing guide included, UK spelling/grammar defaults.
5. **One price, complete book.** No per-word metering, no surprise charges.

## Differentiators vs Competitors

| Product | Gap InkWeave fills |
|---|---|
| ChatGPT / Claude.ai | Requires prompt engineering. No structured book output. No payment flow. |
| Sudowrite | Chapter-by-chapter assistant. Still needs user to drive. No full generation. |
| Jasper | Marketing copy focus. Not book-length manuscripts. |
| Scrivener | Writing organiser, not AI generator. Requires author to write. |
| Novel Factory | Template/plotter. Still needs author to write content. |

## Target Customer

- First-time authors 25–55
- "Always wanted to write a book" demographic
- Non-fiction experts (coaches, consultants, entrepreneurs) who have ideas not writing skills
- UK-based, comfortable paying £20–£50 for a complete service
