# InkWeave — Product Overview

## Definition

AI-powered book-writing platform. Users submit snippets — raw ideas, scenes, notes, character sketches — and InkWeave weaves them into a full, structured manuscript. Targeting aspiring authors who have ideas but not the craft or time to produce a complete book.

Launch: UK. Expand to US/global.

## Core Product

| Layer | What |
|---|---|
| Input | Text snippets from user (scenes, ideas, notes, dialogue, outlines) |
| Engine | AI model orchestration: structure → expand → refine → compile |
| Output | Full manuscript (chapters, formatted book-ready PDF/EPUB/DOCX) |
| Control | Session remote control — user steers AI direction in real-time |

## Product Tiers

| Tier | Product | Role |
|---|---|---|
| Free | 1 chapter sample from snippets | Funnel / trial |
| Core | Full book generation (up to 80k words) | Primary paid product |
| Add-on | Professional edit pass | AI copyedit + style polish |
| Add-on | Cover design prompt pack | AI cover brief + Midjourney prompts |
| Add-on | Publishing guide (UK) | Self-pub checklist, ISBN, KDP, IngramSpark |
| Premium | Session remote control | Live steering of AI during generation |
| Premium | Co-author mode | Multiple snippet contributors for one book |

## Revenue Streams

1. Per-book generation fee (one-time or subscription)
2. Add-on upgrades (edit, cover, publishing guide)
3. Session remote control subscription
4. Affiliate: UK self-publishing services (Reedsy, SilverWood, IngramSpark)
5. Future: white-label API for writing schools / publishers

## Strategy

Free chapter sample converts to full book purchase. Add-ons upsell at completion moment (when user sees their book). UK publishing ecosystem integration builds trust. Session remote control differentiates from pure batch generators.

## Why It Exists

- Millions want to write a book but stall after first few scenes
- Existing AI tools (ChatGPT etc) require users to prompt-engineer everything — too technical
- No dedicated snippet-to-book pipeline product exists
- UK has strong reading culture + active self-publishing market
- Session remote control solves the "AI went off-track" problem that kills trust
