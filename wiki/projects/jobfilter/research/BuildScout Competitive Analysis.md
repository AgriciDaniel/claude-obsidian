# BuildScout — Deep Competitive Analysis

## What BuildScout Is

UK construction lead generation platform. Official partner of the Federation of Master Builders (FMB). Core model: scrape planning applications from UK councils, let builders draw target areas on a map, filter by project type / value / stage, then auto-send physical letters to homeowners.

## Core Features

| Feature | Detail |
|---------|--------|
| Data source | UK planning portals (daily updates) |
| Outreach | Physical direct mail (letters, postcards, flyers) |
| Targeting | Draw custom areas, filter by project type, property value, planning stage, materials, keyword search in documents |
| CRM | Basic — mark leads "responded", add notes/tags |
| Documents | Download plans, drawings, forms in-app |
| Tracking | QR codes on letters, campaign reporting |
| Support | Dedicated Customer Success Manager, onboarding calls |

## Target Audience

- UK SME builders, extension specialists, loft conversion firms
- Electricians, roofers, plumbers, kitchen fitters, driveway/patio installers
- Residential contractors who sell direct-to-homeowner

## Strengths / Moats

1. **FMB partnership** — exclusive credibility and member discount channel
2. **Daily data** — claims same-day updates vs weekly competitors
3. **Keyword search in documents** — scans planning drawings/proposals for specific words (e.g., " oak kitchen ", "bi-fold doors")
4. **Full-service onboarding** — CSM designs letters, sets up campaigns
5. **Physical mail focus** — high-quality designed letters, printed, stamped, sent
6. **Architect network** — alerts on architect planning submissions for referral building

## Weaknesses / Gaps to Exploit

1. **Physical-only outreach** — No email, WhatsApp, or digital sequences. Letters take days. JobFilter can do instant digital delivery.
2. **UK-only, construction-only** — Very narrow niche. No expansion path to other trades or regions without rebuilding data pipelines.
3. **Expensive** — £200-£500/month + per-letter costs. For a builder sending 100 letters/month, cost per lead is high.
4. **Limited coverage** — Householder + small residential only. No commercial/industrial/infrastructure (per SiteLens comparison).
5. **No real-time pipeline** — Batch letter campaigns, not a live feed of actionable leads.
6. **Poor QR tracking** — Trustpilot review notes QR codes show zero scans despite website traffic increasing. Attribution is broken.
7. **Upfront payment lock-in** — Non-FMB members must pay annually. Creates friction for trial.
8. **No self-serve AI** — Human CSM does all setup. No AI refinement of outreach copy.
9. **No outcome tracking** — "Mark as responded" is the only pipeline stage. No quote → won → lost funnel.
10. **No competitor intelligence** — Does not show which other builders are targeting the same leads.

## How JobFilter Beats BuildScout

| BuildScout Limit | JobFilter Advantage |
|------------------|---------------------|
| Physical letters only | Instant WhatsApp, email, SMS, push notifications |
| £200-£500/mo + per-letter | Flat SaaS pricing with unlimited digital outreach |
| No real-time feed | Live scan + alert pipeline (new planning → instant notification) |
| Basic "responded" CRM | Full outcome tracking: delivered → opened → contacted → quoted → won → lost |
| No outcome analytics | ROI dashboard showing cost per lead, cost per win, territory performance |
| UK construction only | Expandable to any trade, any region with data source adapters |
| Annual upfront for non-FMB | Monthly/annual with free tier and transparent pricing |
| Human CSM bottleneck | Self-serve onboarding + AI copy refinement |
| Broken QR attribution | Digital link tracking + UTM + conversion events |
| No signal of competitor activity | Shared directory intelligence (who else is bidding) |

## Moats JobFilter Should Build

1. **Speed-to-lead** — Notify tradesmen within minutes of planning submission, not days via post.
2. **Outcome data network effect** — The more tradesmen report outcomes, the better the lead scoring for everyone.
3. **Multi-channel delivery** — WhatsApp + email + SMS sequences, not just one letter.
4. **AI copy refinement** — Auto-generate personalised outreach based on project details.
5. **Competitive scarcity signals** — Show urgency: "3 other builders viewed this lead today."

## Trustpilot Sentiment Summary

- **Positive:** Good support, helpful team, straightforward platform, more leads than previous tool.
- **Criticism:** QR codes don't track reliably, not enough time to judge effectiveness, some leads don't match criteria despite filters.
- **Verdict:** Users see potential but measurement/attribution is weak.

## Strategic Takeaway

BuildScout proves the market (UK tradesmen will pay £200+/mo for planning leads). But their model is built on **physical mail latency** and **high touch onboarding**. JobFilter's opportunity is to be the **digital-native, self-serve, instant-delivery** alternative with better outcome tracking and lower cost per lead.
