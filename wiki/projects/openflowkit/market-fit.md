# OpenFlowKit — Market Fit and Competitor Landscape

## Competitor Matrix

| Product | Platform | Local/Cloud | Writing Modes | Sharing | Open Source |
|---|---|---|---|---|---|
| Wispr Flow | Desktop (Mac/Win) | Cloud-heavy | None | None | No |
| Superwhisper | Mac only | Local (Whisper) | None | None | No |
| VoiceInk | Cross-platform | Cloud | None | None | No |
| OpenWhispr | Cross-platform | Local | None | None | Yes |
| **OpenFlowKit** | **Browser** | **Local-first** | **6 modes** | **Speak-to-Share URL** | **Yes (repo public)** |

## Competitor Gaps

**Wispr Flow**
- Polished UX and good accuracy
- Proprietary and cloud-heavy (data leaves device)
- Desktop-only installer required
- No output modes, no sharing
- Gap: privacy-conscious users and browser-first workflows left uncovered

**Superwhisper**
- Uses local Whisper model (good for privacy)
- Mac-only, desktop install required
- No writing modes, raw transcription only
- No sharing capability
- Gap: non-Mac users, mode-shaped output, team sharing

**VoiceInk**
- Basic transcription, functional but thin
- No output refinement or modes
- Cloud-dependent
- Gap: all of the above

**OpenWhispr**
- Open source, local-first
- No output refinement or writing modes
- No sharing feature
- Good privacy, poor output quality shaping
- Gap: modes and sharing

## Where OpenFlowKit Wins

- Only browser-native option (no install, works on any device with a browser)
- Only product with structured writing modes baked into the output pipeline
- Only product with Speak-to-Share (URL-encoded, client-side, no backend)
- Privacy-first without sacrificing output quality
- Developer mode is unique across all competitors

## Target User Segments

1. **Privacy-first professionals** — don't want cloud dictation (legal, healthcare, finance)
2. **Developers** — want code-aware voice input (Code mode, camelCase/snake_case)
3. **Remote workers** — Slack and Email modes reduce formatting friction
4. **Teams** — shared vocabulary and snippet library for consistent voice
5. **Occasional users** — Speak-to-Share works without account or install on recipient end

## Market Positioning

Browser-native, local-first, mode-aware voice dictation. The only option that shapes output for context automatically rather than dumping raw transcription.
