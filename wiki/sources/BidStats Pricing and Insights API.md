# BidStats Pricing and Insights API

Official pricing page for BidStats.

## What it contributes

- Free: £0, 5 tender views per day, 3 portals, 90 days.
- Standard: £35 monthly or £350 yearly, top 3 portals, 12 months.
- Pro: £80 monthly or £800 yearly, 3 seats, 3,000+ buyers, 5 years, exports.
- Insights: from £5,000 yearly, 10 years, API/CRM integration, pre-procurement opportunities, public spend, frameworks, organisations, and contacts.

The page offers a demo for Insights rather than self-serve API access. No public endpoint, API key process, quota, or authentication documentation was found on the official BidStats domain.
