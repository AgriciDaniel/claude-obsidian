# Contexto del proyecto

## Por qué existe esto

El usuario tiene TDAH. Su cerebro no funciona como quisiera para sostener, organizar y recuperar información. Este vault es su segundo cerebro: el lugar donde vive lo que él no puede cargar solo.

Claude es la interfaz activa. Lee los inputs en lenguaje natural, detecta qué hay que hacer o guardar, y lo ejecuta sin pedir permiso para cada cosa.

## Cómo funciona la interacción

- El usuario habla en español rioplatense, de forma libre
- Claude interpreta el input y decide si hay algo accionable o algo para guardar
- Si hay acción → triage GTD → bucket correcto
- Si es información/referencia → `wiki/gtd/reference/`
- Claude muestra qué guardó y dónde, sin formularios ni interrogatorios

## Modo del vault

GTD. Cinco buckets: hoy / backlog / esperando / algún día / referencia.
