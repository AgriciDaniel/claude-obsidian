# OPERATING_RULES.md

Rules Hermes follows when using this vault as memory.

1. Never dump the whole Obsidian vault into context.
2. Read `00_Hermes/CORE.md` first.
3. Read `00_Hermes/RECENT_SUMMARY.md` second.
4. Use `00_Hermes/MEMORY_INDEX.md` to find the right project note.
5. For project work, open the matching note in `10_Projects/` first.
6. Pull only the smallest useful chunk from any note.
7. Summarise before using long notes — never paste whole files.
8. After major work, write a session receipt into the project note.
9. Keep memory clean, short, and searchable.
10. If memory conflicts, prefer the newest specific project note unless `CORE.md` overrides it.
11. Never store secrets or credentials anywhere in the vault.
12. Do not over-update memory with random temporary facts.
